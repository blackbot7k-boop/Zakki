模板模式下，菜单栏图标为黑色 + 透明度，由 macOS 自动在浅/深色菜单栏中反色（IconIsTemplate: true）； 「固定白色」对应当前实现；「彩色点缀」保留标签色，仅部分方案有彩色版本。
导出：应用图标为 1024×1024 PNG（可直接替换 resources/icon.png）；菜单栏图标为 @2x 尺寸 PNG（高 36px）。 「雑 · 印章」依赖系统 CJK 字体渲染，正式采用时需转成路径。
