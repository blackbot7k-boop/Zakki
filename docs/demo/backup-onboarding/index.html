备份初始化向导与外部备份目的地

设计稿 · docs/demo 不参与构建 · 真实应用为 MyGo 原生 UI（无 HTML/webview）

进入首启向导的设置 4 步

  1. 备份目的地文件夹（可选，可跳过）——选云盘文件夹（iCloud / 坚果云 / OneDrive）即得云备份；选 GitHub 仓库的本地 clone 即得版本化备份。应用只负责把备份镜像进去。
  2. Git 自动化（可选，仅当所选文件夹是 Git 仓库时出现）：关闭 / 自动提交 / 提交并推送。不配置则完全不影响使用。
  3. 初始标签数量 1–12（默认 7）——决定首次生成的 tot-md.json 里 tabs 的个数。
  4. 完成页：配置汇总 +「打开备份文件夹」验证入口，完成后进入主窗口。

评估后不放进向导 留设置页

  • 明暗 / 颜色主题：默认跟随系统已合理；向导步骤越少完成率越高。
  • 备份间隔 / 保留数量：默认 5 分钟 / 20 份已覆盖绝大多数场景。
  • 全局热键、字体排版：低频细调，放设置页。
  • 数据目录位置：改动迁移语义且多设备同时开应用有并发覆盖风险，不做——数据仍存应用数据目录，向导只配「备份镜像目的地」。

触发与降级 关键行为

  • 向导仅在全新安装（tot-md.json 不存在）时出现；跳过 = 全默认直接进入。
  • 老用户升级不出向导，从设置页「备份与数据」补配外部备份。
  • 「打开文件夹」降级：未配置外部备份时，打开动作提示并引导先选择文件夹。
  • 每一步都可返回、可跳过；向导不阻塞、不写数据，确认时才落盘。

偏好与数据变化

  • preferences.json v2 → v3：backup 增 mirrorDir（字符串，空 = 未配置）与 gitMode（off / commit / commitPush）。缺键一律按现状取值，零行为变化；旧版本程序读到 v3 按既有「版本超前」规则拒绝并保留原文件。
  • tot-md.json 格式不变：标签数量天然由 tabs 数组承载；首次启动按向导选择生成 N 个标签（第 1 个含欢迎文本，其余为空）。
  • 本地与外部镜像共用「备份保留数量」；镜像目录里只修剪本应用写入的 tot-md-*.json，云盘冲突副本等外来文件不受影响。

实现落点（依赖规则内）

  • internal/prefs：Backup 加字段 + validate 枚举 + v2→v3 migrate + Default；同步更新 docs/configuration.md。
  • internal/notes：Store 注入 MirrorDir；writeBackupLocked 写完本地后镜像 + 镜像修剪；Git 动作经注入的 runner 接口（生产 os/exec 调 git CLI，测试注入假 runner），记录 lastMirror 供状态栏。
  • internal/app：生命周期 WhenReady 判定全新安装 → 先出向导窗口（StateKey: "onboarding"），完成/跳过后再建主窗口；选文件夹用 mygo.Dialog.Open{Directory: true, Parent: win}；设置页「备份与数据」新增卡片；backupLabel 扩展镜像状态。
  • 无需新增 internal 依赖边（notes 仍只依赖标准库 + atomicfile），arch-check 不变；文件职责变化随实现提交更新 docs/architecture.md。

边界与风险

  • 目录校验：拒绝选应用数据目录与其 backups/（自我嵌套）；选定后试写一个临时文件验证可写；.git 存在则判定为 Git 仓库。
  • 失败语义：镜像 / git 失败只警告并如实上报（状态栏 + 日志），绝不阻塞本地备份与退出；push 默认关闭，失败不重试（下次备份自然重试）。
  • Git 细节：仅 add tot-md-*.json；无变更则跳过 commit；提交信息 backup: tot-md-<时间戳>；缺 user.name/email 时 commit 失败并在设置页提示检测。
  • 向导不写盘：所有选择先存草稿，确认时经 updatePreferences 统一落盘；跳过则只按默认值建数据文件。
  • 分阶段交付：A = 偏好字段 + 设置页外部备份 + 镜像；B = 首启向导（含标签数初始化）；C = Git 自动提交 / 推送（可选项）。
说明：本页为交互设计稿，模拟三层界面共用同一份演示状态（在向导里选的文件夹会同步反映到设置页与主窗口底栏）。 「选择文件夹…」在真实应用中调 mygo.Dialog.Open{Directory: true} 原生选择器，此处用预设路径模拟；可多次点击/换 chip 体验「云盘 → Git 仓库」两种形态对第 4 步与设置页 Git 行的联动。
