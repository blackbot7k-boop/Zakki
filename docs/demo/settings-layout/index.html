设置页布局方案对比

Zakki · 基于 settings_ui.go 现状分析 · 窗口均为可交互 demo

当前布局的主要问题（按影响排序）

  1. 预览与操作脱节：外观页 5 个分组竖向堆叠，预览在最底部——改完主题要滚到底才能看效果；且预览不应用「排版微调」的字号/行高覆盖，调了等于盲调。
  2. 反馈缺失（bug）：备份页「立即备份」失败把错误写进 keyErr，而这个字段只在快捷键页渲染——备份失败没有任何可见提示。
  3. 滚动行为不一致：只有外观页包了 Scroll；常规/备份页在最小窗口（640×480）下内容会被裁切且无法滚动。
  4. 空间利用差：190px 侧栏只放 4 个 2~4 字的条目，占去 25% 宽度；常规页只有 3 个开关，大片空白；备份路径用 11px 灰字展示，不可选中复制。
  5. 选择器信息不足：颜色主题卡片只有 3 个 18px 色块，排版主题只有一行文字描述——都无法预判实际效果；窗口收窄到 minWidth 时 5 张卡片挤成一行。
  6. 「恢复默认值」位置飘：每页右下角悬浮，稀疏页面上视觉重心奇怪，外观页则要滚到底才看得到。
