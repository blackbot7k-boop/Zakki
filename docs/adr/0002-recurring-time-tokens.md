# 重复提醒采用规则令牌、完成时锚点推进与自动跳过

ADR-0001 的一次性时间令牌（`@时刻` + `~提前量`）覆盖不了固定循环的需求（每天、每周、
每个工作日、每月、每年）。重复语义必须继续以行内文本承载（文本即数据、可导出、可 Git
diff、源码可编辑），且语法是桌面与移动端共享的契约。我们决定：在时间令牌簇内新增可选
`^` 段表达重复规则；实例由调度器从锚点展开；任务行勾选完成时把锚点改写推进；重复任务
永不过期（自动跳过），后台绝不改写正文。

## 决策

**语法**：`^<次数?><单位>[@<周几集>][<结束日期>]`

| 场景 | 写法 |
|---|---|
| 每天 | `^1d` |
| 每个工作日 | `^w@1-5`（周几 ISO，1=周一；区间与列表皆可：`@1-5`、`@1,3,5`） |
| 每周（保周几） | `^1w`；双周 `^2w` |
| 每 3 天 | `^3d` |
| 每月（保几号）/ 每年（保月日） | `^1mo` / `^1y` |
| 结束日期 | `^1d<2025-12-31`（`<` 读作 until） |

- 单位只有 `d`/`w`/`mo`/`y`（日历感知）；不做分钟/小时（消耗 iOS 64 条 pending 配额，属闹钟领域）。
- 次数缺省为 1；次数 >1 不可与周几集组合（v1）。
- 「每月第几个周几」等未来参数在 `^` 段内以新分隔符追加——该段是参数化扩展点；旧解析器
  把无法识别的规则视为普通文本（不触发、不迁移、不报错），解析器带版本号。

**实例展开**：令牌永远存规则，不存实例。调度器从锚点展开未来地平线内的实例（桌面 60 天；
iOS 在 64 条 pending 配额内填实例，可整除自然单位的规则可选用平台原生重复触发器省配额）。
`~提前量` 作用于每个实例。

**完成推进**：勾选完成重复任务是编辑动作——把 `@` 锚点改写到当前实例的下一个时刻（从
到期日推进，非完成日）。补勾不追账：错过三天再勾也只前进一步。可撤销、Git diff 可见；
后台绝不改写正文。

**过期自动跳**：重复任务永不过期。派生层把「当前实例」定义为序列中不晚于当下的最近一个，
错过的实例自动跳过（虚拟推进，零文本改写）；「过期」概念仅属非重复任务。

**不存在日期跳过**：每月/每年规则遇到不存在的日期（1/31→2 月、2/29→平年）该期不发生
实例（宁缺不错，用户拍板）。

## Considered Options

- **结构化元数据存重复**（zakki.json 加字段）：拒绝——同 ADR-0001，迫使文本操作维护行映射，破坏文本唯一事实源。
- **英文枚举**（`^daily`/`^weekly`）：表达不了「每 3 天」「每两周」「工作日集合」，与 `~10m/1h` 的时长风格不一致。
- **`*` 等其他记号**：`*` 与 Markdown 强调冲突；`^` 在 CommonMark 无任何内联语义，零冲突。
- **从完成日推进**：补勾会让序列漂移（滴答清单的可选风格），不可预期，弃。
- **过期任务后台自动推进/跳过**：后台改写正文，与写保护、外部改动检测、Git diff 纯净性全部冲突，弃。
- **月末夹逼**（1/31→2/28）：被「跳过」替代——用户选择宁缺不错，避免「这个月怎么没提醒」的另一种困惑。
- **以 iOS 原生重复触发器为主**：表达不了周几集合与任意间隔，只能作为可整除自然单位规则的配额优化。

## Consequences

- 桌面调度器从「单次定时器」升级为「实例展开」；时间弹层增加重复选择器（无/每天/工作日/每周/每月/每年/自定义）。
- 实例展开逻辑进入 gomobile 共享内核：客户端主循环「打开即对账全量重排」天然消费它，双端行为一致。
- 重复任务不出现在过期场景中；过期列表/状态展示范围随之收窄。
- ADR-0001 的派生规则（时刻在未来且非任务或未完成 → 排定）扩展为按实例展开后逐实例判定。
- 语法契约同时约束桌面（解析/弹层/调度）与移动端（规格见 wayfinder #8）；桌面实现本身仍在本图范围之外。
