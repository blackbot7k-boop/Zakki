# 重复提醒采用规则令牌、完成时锚点推进与自动跳过

> 下方「决策／Considered Options／Consequences」保留原始记录；现行口径以文末
> [2026-10-28 修订](#2026-10-28-修订统一实例语法与日历边界) 为准，旧段落不是并行有效的契约。

ADR-0001 的一次性时间令牌（`@时刻` + `~提前量`）覆盖不了固定循环的需求（每天、每周、
每个工作日、每月、每年）。重复语义必须继续以行内文本承载（文本即数据、可导出、可 Git
diff、源码可编辑），且语法是桌面与移动端共享的契约。我们决定：在时间令牌簇内新增可选
`^` 段表达重复规则；实例由调度器从锚点展开；任务行勾选完成时把锚点改写推进；重复任务
永不过期（自动跳过），后台绝不改写正文。

## 决策

**语法**：`^<次数?><单位>[@<周几集>][<结束日期>]`

| 场景 | 写法 |
|---|---|
| 每天 | `^1d` |
| 每个工作日 | `^w@1-5`（周几 ISO，1=周一；区间与列表皆可：`@1-5`、`@1,3,5`） |
| 每周（保周几） | `^1w`；双周 `^2w` |
| 每 3 天 | `^3d` |
| 每月（保几号）/ 每年（保月日） | `^1mo` / `^1y` |
| 结束日期 | `^1d<2025-12-31`（`<` 读作 until） |

- 单位只有 `d`/`w`/`mo`/`y`（日历感知）；不做分钟/小时（消耗 iOS 64 条 pending 配额，属闹钟领域）。
- 次数缺省为 1；次数 >1 不可与周几集组合（v1）。
- 「每月第几个周几」等未来参数在 `^` 段内以新分隔符追加——该段是参数化扩展点；旧解析器
  把无法识别的规则视为普通文本（不触发、不迁移、不报错），解析器带版本号。

**实例展开**：令牌永远存规则，不存实例。调度器从锚点展开未来地平线内的实例（桌面 60 天；
iOS 在 64 条 pending 配额内填实例，可整除自然单位的规则可选用平台原生重复触发器省配额）。
`~提前量` 作用于每个实例。

**完成推进**：勾选完成重复任务是编辑动作——把 `@` 锚点改写到当前实例的下一个时刻（从
到期日推进，非完成日）。补勾不追账：错过三天再勾也只前进一步。可撤销、Git diff 可见；
后台绝不改写正文。

**过期自动跳**：重复任务永不过期。派生层把「当前实例」定义为序列中不晚于当下的最近一个，
错过的实例自动跳过（虚拟推进，零文本改写）；「过期」概念仅属非重复任务。

**不存在日期跳过**：每月/每年规则遇到不存在的日期（1/31→2 月、2/29→平年）该期不发生
实例（宁缺不错，用户拍板）。

## Considered Options

- **结构化元数据存重复**（zakki.json 加字段）：拒绝——同 ADR-0001，迫使文本操作维护行映射，破坏文本唯一事实源。
- **英文枚举**（`^daily`/`^weekly`）：表达不了「每 3 天」「每两周」「工作日集合」，与 `~10m/1h` 的时长风格不一致。
- **`*` 等其他记号**：`*` 与 Markdown 强调冲突；`^` 在 CommonMark 无任何内联语义，零冲突。
- **从完成日推进**：补勾会让序列漂移（滴答清单的可选风格），不可预期，弃。
- **过期任务后台自动推进/跳过**：后台改写正文，与写保护、外部改动检测、Git diff 纯净性全部冲突，弃。
- **月末夹逼**（1/31→2/28）：被「跳过」替代——用户选择宁缺不错，避免「这个月怎么没提醒」的另一种困惑。
- **以 iOS 原生重复触发器为主**：表达不了周几集合与任意间隔，只能作为可整除自然单位规则的配额优化。

## Consequences

- 桌面调度器从「单次定时器」升级为「实例展开」；时间弹层增加重复选择器（无/每天/工作日/每周/每月/每年/自定义）。
- 实例展开逻辑进入 gomobile 共享内核：客户端主循环「打开即对账全量重排」天然消费它，双端行为一致。
- 重复任务不出现在过期场景中；过期列表/状态展示范围随之收窄。
- ADR-0001 的派生规则（时刻在未来且非任务或未完成 → 排定）扩展为按实例展开后逐实例判定。
- 语法契约同时约束桌面（解析/弹层/调度）与移动端（规格见 wayfinder #8）；桌面实现本身仍在本图范围之外。

### 规则语法与兼容

规则语法版本（RuleSyntaxVersion）为 **1**：`^<次数?><单位>[@<周几集>][<结束日期>]`。
它独立于 `zakki.json` 数据版本，新增文本语法不隐式升级文件格式。

重复场景写法沿用原始语法表；结束日期 `<YYYY-MM-DD` 包含当天，以所选时区的日历日判定。

- 单位只有 `d`、`w`、`mo`、`y`，不支持分钟／小时。次数 Every 缺省 1，范围 **1..999**，
  不接受 0、负数、前导零或溢出。周几集严格匹配 `n(-n)?(,n(-n)?)*`（n 为 1..7 的单个数字），
  区间不可倒序，仅限 `w` 且 Every=1，解析后升序去重；规则内部不允许空格。
- 结束日期必须严格匹配真实有效的 `YYYY-MM-DD`；规则必须整段读尽，不能把
  `^w@1-5x`、`^w@1-5#2` 等未来扩展识别为旧规则。
- `@YYYY-MM-DD HH:mm` 后的 `~`、`^` 两种顺序均接受，**每段至多一次、段间单个 ASCII 空格**。
  规范写回固定为 `@时刻 ~提前量 ^规则`，未启用的段省略；不跨正文吸收附加段。
- 紧邻令牌簇的非空未知或非法 `^` 段使**整簇成为普通文本**：不渲染时间组件、不调度、
  不推进、不自动迁移，不能退化成按锚点响一次。Find、Replace 的查找、Split、桌面和移动
  入口都采用同一判定；无合法令牌是正常结果。直接调用 ParseRule 校验未知规则则返回错误。
  未知簇之后若另有合法令牌，可继续按 ADR-0001 的首个合法令牌规则识别。
  `^` 后为空白或行尾时按普通正文处理，不作为重复段吸收。
- `~` 只接受共享白名单，禁止前缀识别（`~10min` 不等于 `~10m`）；重复附加段
  不能导致部分识别、删除残片或重复写回。

### 实例、当前实例与推进

令牌存锚点和规则，不存展开结果。实例按所选时区的日历展开，精度为分钟，**秒和纳秒清零**。
`~` 提前量逐实例生效，触发时刻 `fireAt = due - alert`；没有 `~` 就没有通知。

**当前实例（Occurrence）**：序列中不晚于 now 的最近一个实例；若尚无这样的实例，则取序列
首个实例。若序列根本没有合法实例，返回 `ended=true`。即使 now 已越过结束日期，只要过去
存在实例，当前实例仍是最后一个合法实例，chip 显示层保持中性，不染过期色。
当前实例查询不受提醒展开地平线限制。

**完成推进（Advance）**：取当前实例之后的首个合法实例；超过 end 或没有后继时返回
`ended=true`，不伪造下一锚点。勾选重复任务完成是可撤销的编辑动作：有后继时把 `@` 改写到
该后继，保留规则和提前量，并维持任务未完成以继续下一轮；ended 时勾选完成并保留末次锚点，
不再调度。非任务行不做完成推进。

例如每日 09:00 的任务锚点为 10 月 1 日，现在为 10 月 4 日 12:00，当前实例是 4 日 09:00，
完成后推进到 5 日 09:00；不会仅把旧锚点加一天留在 2 日。若首实例还在未来，提前完成也推进
到该首实例的下一实例。补勾不逐笔追账，后台的虚拟跳过不产生文本修改。

**过期自动跳**：重复任务不以历史锚点显示过期；展示消费当前实例。只有非重复且未完成的
任务具有 ADR-0001 的过期状态。结束的重复任务显示结束／完成状态，不继续生成通知。

### 日历边界、DST 与地平线

- 每月／每年遇到不存在的日期（1 月 31 日到 2 月、2 月 29 日到平年）跳过该期，不夹逼月末。
- **DST 空档不跳过当天**。每一个候选日都用锚点原始墙上钟的小时、分钟重新构造
  `time.Date(..., hour, minute, 0, 0, location)`；gap 当天接受 Go 的归一化结果，随后实例仍从
  锚点钟点重建，恢复原小时分钟。不得在上一个归一化实例上持续 AddDate 导致永久漂移。
  秋季重叠钟点也采用同一 `time.Date` 选择，只生成一个实例，不另外复制第二个偏移实例。
  源码直接输入的不存在墙上时刻由令牌校验一致拒绝；此处归一化仅指合法锚点展开遇到 DST。
- Expand 窗口按**实例时刻**判定：`(now, now + horizonDays 个日历日]`，不是按 fireAt 判定。
  桌面默认 60 天；窗口外实例即使其提前触发时刻落入窗口，也不纳入本次展开。
  客户端定期重排，不能承诺窗口之外的提醒已注册。
- Expand 返回至多 maxCount 个升序实例；非正地平线／数量返回 `[]`，空结果也必须为 `[]`。
  Every、日期、规则 JSON 在展开入口重新校验，拒绝卡死和 panic；当前实例与推进要直接定位
  周期，不能用 60 天窗口替代（例如年度任务的后继通常在窗口之外）。

### 实施影响

共享内核拥有令牌与重复语义；客户端负责 Markdown 保护区、块分类、完成状态、正文投影与系统通知。
桌面消费 `^` 的最小配套（当前实例展示、不报过期、完成推进、逐实例调度、弹层保留规则）属于
本分支的桌面实施范围；本节修订不表示移动端已实现。双端均展开单次实例，不使用平台原生重复触发器。
