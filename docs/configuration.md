# 偏好与设置（preferences.json 与数据快照）

Zakki 的偏好分两层，都由应用内原生设置窗口管理，正常使用不需要编辑任何配置文件：

- **界面语言**：`appearance.language`（空 = 跟随系统，`en` / `zh-Hans`）；首启向导第一步选择，
  设置「常规」页与应用菜单可随时切换，变更经 MyGo `App.SetLocale` 即时生效并持久化。

- **preferences.json**（数据目录）：明暗模式、颜色/排版主题、字体、备份策略、
  快捷键、窗口参数。
- **笔记数据快照（zakki.json）里的标签与外观设置**：标签内容/名称/颜色、
  标签标题最大宽度、切换动画速度、顶栏动效开关、标签形状、彩色圆点、毛玻璃回退强度——这些跟随笔记
  自动保存落盘，在「标签」与「外观」页即时生效，无需重启。

macOS 路径：

```text
~/Library/Application Support/Zakki/preferences.json
~/Library/Application Support/Zakki/zakki.json
```

Windows 的对应目录为 `%APPDATA%\Zakki\`，与默认程序安装目录 `%LOCALAPPDATA%\Programs\Zakki` 分离。
更名前安装的旧数据目录会在升级后首次启动时自动迁移到新目录（整体搬入并按新命名改名文件，
新目录已有数据时不动旧目录仅告警）；其他平台两个文件位于同一数据目录（os.UserConfigDir）。
MyGo 的 `PathUserData` 同样指向此目录，窗口状态与更新器辅助状态不会另建目录。
开发运行（`go tool mygo dev` / `go run`，即 `mygo.IsDev()`）使用独立的
`~/Library/Application Support/Zakki Dev/`，不做旧目录迁移；正式目录留给安装版
（本地 `make build` 产物也算正式），两边数据互不污染。
`updater.json` 由 MyGo 原生更新器管理检查时间、跳过版本和自动下载选择，不改动 `preferences.json` 的结构。
默认只手动检查；更新入口及发布要求见 [发布与更新](release.md)。

## 设置窗口

单实例、非模态窗口，独立记忆位置和尺寸（初始 760×600，最小 640×480）；
重复打开只聚焦已有窗口，应用菜单只保留「设置… ⌘,」一个入口，标签、外观、快捷键等页面从设置窗口左侧导航进入。
所有字段**即时生效并自动保存**；非法数字不提交，保留正在编辑的输入并显示行内错误；
每页提供「恢复本页默认值」（需确认，不清除笔记或备份；标签页除外——
标签内容属于笔记数据，用删除/清空入口并走安全备份）。

### 标签

标签是动态的：默认 7 个，最多 9 个，至少保留 1 个。标签内容、名称与颜色
属于**笔记数据**（存在 zakki.json 的 `tabs` 里，随自动保存与退出最终保存落盘）。

| 设置/操作 | 行为 |
|---|---|
| 标签列表 | 上下拖拽排序（当前选中跟随被拖的标签）、行首圆点点开取色器（含常用色板，实时生效）、名称双击行内重命名（未命名只显示圆点）、行尾删除图标；不显示 ⌘1–9 提示与「当前」徽标（当前行有浅色底） |
| 删除 | 行尾垃圾桶图标；至少保留 1 个；有内容的标签先弹居中于主窗口的原生确认（回车默认落在「取消」），确认后先做安全备份，备份失败自动取消 |
| 新建标签 | 新增空标签并切换过去、聚焦内容编辑；自动分配未使用的调色板颜色；达到 9 个显示原因 |
| 标签标题最大宽度 | 80–220 DIP（默认 120）；超出用 … 省略 |
| 切换动画速度 | 慢 / 正常 / 快 / 更快（圆点滑到新标签的速度） |
| 顶栏动效 | 关闭后切换标签立刻完成；与系统「减少动态效果」同路径 |
| 标签形状 | 圆点（默认）/ 圆环。未命名时每枚一样大，当前标签只是颜色更深；有名字时，名字写在当前标签的色条里。旧文件里的其他形状载入时回退为圆点 |
| 毛玻璃回退强度 | 无系统材质平台上的半透明层浓度（20–90%） |


### 常规

| 设置 | 行为 |
|---|---|
| 窗口置顶 | 即时生效（与 ⌥⌘T、工具栏置顶按钮同源） |
| 按 Esc 隐藏窗口 | 即时生效 |
| 记忆主窗口位置与尺寸 | 从**下次创建主窗口**起生效（关闭窗口后重新打开即应用），无需重启应用 |
| 默认宽度 / 默认高度 | 新建主窗口时的尺寸（宽 300–4096，默认 400；高 340–4096，默认 540）。已记住位置的窗口仍用上次的大小 |

页内同时显示一次性迁移结果，以及偏好文件/旧配置异常时的恢复入口。

### 外观

- **顶栏**（自原「标签与外观」页迁入）：标签形状（圆点/圆环）、标签标题最大宽度、切换动画速度、顶栏动效开关、毛玻璃回退强度。
- **明暗模式**：跟随系统 / 浅色 / 深色，即时应用到已打开窗口。只在「外观」页调整。
- **整套主题**：「手绘手账」一键同时套用手绘颜色主题、手账排版主题与手写正文字体（之后仍可分别调整）。
- **颜色主题**（与排版相互独立；点「手绘」卡片会同时切到手账排版与手写字体）：经典（随标签七色配色）、纸白、暖砂、雾青、石墨、手绘（米黄纸张 + 朱红批注 + 荧光笔选区）、Claude（Anthropic 暖象牙与近黑、橙 accent）、Qoder（Forest 白绿浅色与灰绿深色）；
  每套均有浅/深两组底色，正文/次级文字对实际背景 ≥ 4.5:1（有自动化对比度测试）。
  主窗口自液态标签版起使用**窗口级毛玻璃（Vibrancy）+ 中性背景**，不再随标签
  切换整片内容背景色；标签颜色只出现在圆点/胶囊、焦点 accent 与状态栏小标识上。
  macOS 提供系统材质；不支持材质的平台自动回退为主题半透明色，强度可在
  「外观」页调整，功能不受影响。
- **Markdown 排版主题**：Sonnet（Typora）、便签、清晰（16px/1.65）、
  书页（宋体 17px/1.8）、紧凑（15px/1.5）、手账（16px/1.75；点阵纸与页边红线、铅笔线框代码块与表格、马克笔引用条、荧光笔标题与粗体、波浪下划线链接、手绘勾选框与列表符号、铅笔波浪分隔线）；标题字号 = 正文基准 × 主题比例。
- **排版微调**：中文字体（霞鹜文楷 / 系统苹方 / 宋体 / 手写 / 手札体：手写与手札体同用
  霞鹜文楷 Lite，标题靠字号与装饰区分）、西文字体（跟随中文字体 / JetBrains Mono / 系统西文 /
  Noteworthy / Bradley Hand / Fira Code）、代码字体（JetBrains Mono / SF Mono / Menlo /
  Fira Code）、字号（10–40）、行高（1–3）；三个字体下拉均合并本机已装字体（`local:<家族名>`，
  免下载；代码字体只列等宽家族），霞鹜文楷 Lite / JetBrains Mono / Fira Code 本机缺失时
  标注需下载，选中后自动后台下载（展示进度、可取消），成功才写入偏好，失败保留原选择。
  字体不随安装包分发；本机字体卸载后偏好保留、渲染回退并提示。
  清空表示「跟随 Markdown 排版主题」。主题切换不重置显式覆盖。
- **代码配色**：代码块语法着色方案（柔和 / 明快 / Claude / Qoder / 跟随文本），实时预览代码卡与源码模式共用；
  默认「柔和」，「跟随文本」保持单色文字（可显式选择并始终落盘）。逐行浅层词法着色，不保证跨行结构（块注释、多行字符串只有首行着色）。
- **代码块缩进**：代码块内按 Tab 插入的缩进——2 空格（默认）/ 4 空格；
  跨行选区按同档位整行增减，Shift+Tab 反向移除一级（行首是制表符的粘贴内容也按一级移除）。
- **代码语言**：活动代码块右下角显示围栏语言（如 `js`），点击即可改写；
  Enter 或点回正文提交，Esc 取消。
- **预览**：只读示例（中英文、标题、链接、代码、引用、任务、表格），
  用所选排版主题 + 当前颜色主题渲染，不套用户覆盖。

### 备份与数据

设置页不再提供编辑间隔、保留份数、启动时备份和立即备份；这些按内置策略执行：
打开应用时先备份、编辑停下后备份、菜单或 ⌘S 立即备份。
备份只有一个文件夹：选择了文件夹，它就是唯一存储地址，每次备份直写那里；
未选择时写入应用数据目录下的 `backups/`。没有镜像和第二份副本。

备份文件夹两种形态，按所选文件夹自动展示其一：

1. **普通文件夹（本地或云盘同步盘）**：只做自动备份，同步与否交给用户；
   选云盘同步文件夹（iCloud、坚果云等）即云备份。
2. **git 仓库**：文件夹探测到 `.git` 时，卡片追加「Git 仓库」区块——总开关
   （默认关，需用户显式开启）与推送间隔（默认 10 分钟）。开启后每次备份自动
   commit 备份文件（含修剪产生的删除；只动备份文件，不影响仓库里其他内容），
   按间隔自动 push；提交/推送失败在卡片状态行显示原因，下个周期自动重试。
   需系统装有 git；macOS 未装命令行工具时静默跳过（不触发系统安装对话框，
   状态行提示一句），装好后下一次备份自动恢复。应用内不提供 `git init`，
   想用 Git 模式请先自行初始化仓库。

| 设置/操作 | 说明 |
|---|---|
| 备份文件夹·选择文件夹 | 每次备份直写该文件夹：云盘同步文件夹（iCloud、坚果云等）即云备份，git 仓库即自动提交推送。拒绝选应用数据目录及子目录（路径解析跟随符号链接），选定后试写验证可写；原生目录选择器可选新建文件夹 |
| 备份文件夹·打开文件夹 / 更换 / 断开 | 打开当前备份文件夹（访达）；未选择时显示「未连接文件夹，当前备份写入：」与内置目录路径及选择入口，无断开。断开后回到内置目录 |
| Git 仓库·自动提交与推送 | 仅备份文件夹是 git 仓库时出现；关闭后该文件夹仍作普通备份用，只是不 commit/push。事后 `git init` 的文件夹在下次备份时自动被识别 |
| Git 仓库·推送间隔 | 两次自动推送尝试之间的最小分钟数（1–1440，默认 10）；失败也计一次尝试，不硬撞 |
| Git 仓库·状态行 | 最近提交/推送时间与最近失败原因；更换备份文件夹后状态作废 |
| 显示数据位置 | 在访达中定位 `zakki.json` |
| 写回数据文件 | 仅当数据文件处于写保护（损坏且无可用备份）时出现；确认后解除保护并写回 |

### 首启初始化向导

仅在**全新安装**（数据文件不存在）时出现，独立窗口（`StateKey: "onboarding-v2"`，640×560），
主窗口等向导结束再创建。两页均可返回，选择只存草稿、不触发下载：

1. **外观与字体**：语言（English / 简体中文，跟随系统初始，选择即时生效并被记住）、明暗
   （跟随系统/浅色/深色）、风格（默认/手账；手账同时选手绘颜色主题与手账排版，不强制更换字体）、
   中文字体与西文字体。字体下拉合并本机已装字体（免下载，含本机购买的商业字体如 Dank Mono）
   与可下载的开放许可字体（霞鹜文楷 Lite / JetBrains Mono / Fira Code，标注「需下载」），
   支持搜索；新装默认中文字体为系统苹方，不随包携带字体文件。
2. **笔记与备份**：初始标签数量 1–9（默认 7，决定首次生成的 `zakki.json` 标签数）与备份文件夹——
   预填默认路径 `~/Documents/Zakki 备份`（目录在首次备份时自动创建），始终可见，
   可点「更换…」改选任意本地文件夹。它就是唯一的备份存储地址；选云盘同步文件夹即云备份。

主按钮按所选字体显示「完成设置」（无需下载）或「下载字体」。提交后统一下载缺失字体：
展示总进度与单字体进度，可返回修改（作废旧下载）或失败后重试/改用系统字体；下载经
长度与 SHA256 校验后私有注册（不写入系统字体库），缓存保存在应用数据目录 `fonts/`。
完成后停在就绪页，点**「开始使用」**才保存偏好与初始数据并进入主窗口；数据落盘失败
留在向导并提示重试。数据保存成功后立即做一次备份，备份失败不阻止进入应用，
状态栏/通知会提示详情。

关闭向导等同接受默认：默认备份路径 + 默认标签数与欢迎文本，以免下次启动再次弹出向导。

老用户升级（已有数据文件）不出向导；已有偏好引用的字体若本机缺失，首次开窗后在后台
静默补齐并注册，失败只记日志、渲染按缺失回退，不改动偏好。

老用户升级（已有数据文件）不出向导，v5 偏好里的 `mirrorDir` 由版本 6 迁移平移为
`backupDir`（原值不变，语义变为唯一备份地址）；从设置页补配或修改备份文件夹。
版本 9 给旧文件补 Git 自动化默认：`gitAutoPush` 关（自动推送会把笔记送到远端，
只能由用户显式开启，迁移不替用户打开）与推送间隔 10 分钟。

### 快捷键

- 可改键命令：加粗、斜体、行内代码、插入或编辑链接、标题 1–6、正文、引用、
  无序/有序/任务列表、代码块、分隔线、插入表格，以及全局显示/隐藏主窗口。
- 标签数字键两平台同形（浏览器惯例）：⌘1–9（macOS）、Ctrl+1–9（Windows），
  标签上限 9 个，数字键全覆盖。标题与正文的数字键退到各平台次级修饰键：
  macOS ⌃1–6 / ⌃0，Windows Alt+1–6 / Alt+0。
- macOS 默认：⌘B / ⌘I / ⌘⇧E / ⌘K、⌃1–6 / ⌃0、⌘⇧Q、⌘⇧8 / ⌘⇧7 / ⌘⇧9、
  ⌘⌥C、分隔线与表格默认未绑定、全局 ⌘⇧空格。其他平台以 Ctrl 替代 Cmd，
  并按上条替换标题修饰键。
- 按键录制：点击「更改」后按下组合键，Esc 取消；仅支持单组组合键（不支持 chord）。录制期间临时摘除应用菜单并注销全局热键（macOS 菜单快捷键与 OS 级热键先于窗口按键被消费，会吞掉录制按键并触发菜单动作），退出录制时统一恢复。
- 拒绝：与已有命令或固定快捷键冲突（显示冲突名称）、仅修饰键、裸字母/数字、
  Tab/Enter/Esc 等导航输入键；全局键不能与文档键相同（避免全局键吞掉文档快捷键）。
- 固定快捷键（不开放改键）：⌘F 搜索、⌥⌘F 查找和替换、⇧⌘F 在所有标签中查找、⌘⇧P 源码模式、⌥⌘T 置顶、
  ⌘= / ⌘- / ⌘0 放大 / 缩小 / 默认正文字号（在当前生效字号上 ±1，限 10–40；
  默认 = 清除覆盖、跟随排版主题；与外观页「正文字号」同一偏好，即时保存）、
  ⌘1–9 切换标签（Windows 为 Ctrl+1–9）、
  ⌘T 新建标签、⌘R 重命名当前标签、⌘⇧D 删除当前标签（Windows 为 Ctrl+Shift+D；
  不用 ⌘W——已是关闭窗口，也不用 ⌥⌘D——macOS 系统占给 Dock 自动隐藏）、
  ⌘⌥←/→ 上/下一个标签（循环）、⌘S 立即备份、⌘⇧C 复制整个标签、
  系统编辑操作（剪切/复制/粘贴/撤销/全选）。删除标签先做安全备份
  （备份失败自动取消），有内容的标签先弹确认，空标签直接删，至少保留 1 个；
  顶栏标签右键菜单也可重命名/删除（与 ⌘R/⌘⇧D 同一实现），双击顶栏胶囊也可重命名。
- 全局热键变更先注册新键，成功后再注销旧键；失败保留旧绑定并提示；
  解除绑定后托盘仍可唤起窗口。

## 标签数据与数据文件版本

笔记数据文件 `zakki.json` 当前版本为 **3**：

```json
{
  "version": 3,
  "active": 0,
  "tabs": [
    { "id": 1, "name": "工作", "text": "# 待办", "color": "#d4253a" },
    { "id": 2, "text": "" }
  ],
  "settings": {
    "themeSource": "system",
    "tabTitleWidth": 120,
    "tabAnimSpeed": 1,
    "monoDots": false,
    "glassStrength": 0.5,
    "tabMotionOff": false,
    "tabDotShape": "dot"
  }
}
```

- `tabs` 是动态标签列表；`name` 空 = 未命名（顶栏只显示圆点）；
  `color` 空/非法时按槽位回退内置 12 色调色板。
- `settings` 里的标签栏外观项（0/缺键 = 跟随默认）：`tabTitleWidth` 80–220、
  `tabAnimSpeed` 0.5–2、`monoDots` 关闭彩色圆点、`glassStrength` 0.2–0.9、
  `tabMotionOff` 关闭顶栏动效（缺键 false = 开启）、`tabDotShape` 标签形状 ID
  （缺键/未知值 = 圆点；合法值见 `tab_strip.go` 常量）。
- 版本 0/1（固定 7 点 `dots` 格式）在读取时按原顺序迁移为 7 个标签：正文原样、
  名称空、颜色用原 7 色；迁移后保存只写 `tabs`，不再写 `dots`。
- 版本 3 起排版主题 ID 更名：旧 ID 字面量（见 `notes` 包常量）载入时映射为 `note`；
  文件结构与字段不变。
  版本高于当前支持时绝不覆盖原文件（隔离原件并尝试从备份恢复）。

## preferences.json 结构

应用自动读写，通常无需关心。手工编辑时注意：未知字段、null 与非法取值会被拒绝，
文件损坏或版本超前时应用不会覆盖原文件，会在设置页提示恢复。

```json
{
  "version": 8,
  "appearance": {
    "appearanceMode": "system",
    "language": "",
    "colorTheme": "classic",
    "markdownTheme": "sonnet",
    "codeTheme": "soft",
    "codeIndent": "space2",
    "bodyFont": "",
    "latinFont": "",
    "monoFont": "",
    "bodySize": 0,
    "lineHeight": 0
  },
  "window": { "alwaysOnTop": false, "hideOnEscape": true, "rememberBounds": true },
  "backup": { "intervalMinutes": 5, "keep": 20, "onLaunch": true, "backupDir": "" },
  "keymap": { "overrides": { "format.bold": "CmdOrCtrl+Alt+U" } },
  "advanced": { "autosaveDelayMs": 800, "windowWidth": 400, "windowHeight": 540 }
}
```

- `appearance.bodyFont` 是中文字体，`appearance.latinFont` 是西文字体：
  两者组合成字体栈（西文在前、中文在后），英文字母与数字取西文，中文字形取中文。
  `latinFont` 空串 = 跟随中文字体，此时整篇用中文字体栈自带的西文字形。
  三个字体字段除预设键外还允许 `local:<真实家族名>`（本机字体，仅按名字引用，不携带文件；
  经严格校验，不接受逗号/控制字符/首尾空白），`latinFont` / `monoFont` 另支持 `fira`。
- `appearance.monoFont` 空串 = 跟随排版主题；`bodySize` / `lineHeight` 0 = 跟随。
- `appearance.codeTheme` 空串 = 跟随文本（单色代码），其余取值 `soft`（柔和，默认）/ `vivid`（明快）；
  该键始终落盘（无 omitempty），空串是显式选择而非未设置。
- 版本 2 起分成中西文两个键。旧文件（版本 1 或无 version）读取时把 `latinFont` 留空，
  与升级前的渲染结果一致；升级后写回的文件为当前版本，旧版本程序会因版本超前而拒绝读取，
  并保留原文件不走覆盖。
- 版本 3 起 `backup` 增加外部备份目录 `mirrorDir`（空串 = 未配置，仅本地备份）与
  Git 自动化档位 `gitMode`。
- 版本 4 起主题 ID 更名：`colorTheme` 旧字面量映射为 `classic`，`markdownTheme`
  旧字面量映射为 `note`（旧字面量见 `prefs` 包常量）；新增 `appearance.language`
  （空串 = 跟随系统，`en` / `zh-Hans`）。缺键行为与升级前一致。
- 版本 5 起代码配色默认「柔和」：版本 4 及更早文件从未写过 `codeTheme` 键，
  升级时统一补为 `soft`；带值文件原样保留。版本 5 文件该键始终写出，
  缺键或空串都按显式「跟随文本」处理，不再补默认。
- 版本 6 起备份只有一个文件夹：`backup.mirrorDir` 更名为 `backup.backupDir` 并成为
  唯一备份地址；`gitMode` 随 Git 自动化移除。旧键值在严格解码前摘除、`mirrorDir`
  平移为新键后写回版本 6；版本 6 文件再出现旧键按未知字段拒绝。
- 版本 7 起代码块缩进只有两档：`appearance.codeIndent` 取 `space2`（默认）/ `space4`。
  旧文件从未写过该键，升级时补默认 2 空格；早期内部构建写过的 `tab` / `space8` 废弃档位
  归为默认 2 空格；新文件缺键或空串同样按默认处理，其余非法取值拒绝。
- 版本 8 仅扩展字体键取值：三个字体字段允许 `local:<真实家族名>`（经校验），
  `latinFont` / `monoFont` 另增 `fira`；不新增 JSON 字段、不改默认字体、不触发下载，
  既有取值原样保留。
- `keymap.overrides` 缺项用默认绑定；显式空串表示解除绑定；值为规范化 accelerator。
- `advanced` 是兼容参数（自动保存防抖毫秒、主窗口初始宽高），不在设置页展示，
  仅在旧配置携带有效值时迁移保留。

## 旧配置文件（仅供迁移）

`config.toml`（及更早的 `config.json`）**只在新版首次启动、且不存在
`preferences.json` 时被读取一次**，优先级：默认值 → 笔记内旧设置 → 旧配置显式值
（TOML 优先于 JSON）。迁移成功以 `preferences.json` 原子写入为完成标志；
两个旧文件此后原样保留、不再读取，应用也不再生成或改写它们。
旧排版值映射到当前排版主题，颜色主题映射为经典主题（保留七点底色体验），
字体覆盖、窗口参数、备份策略与全局热键一并迁移。
