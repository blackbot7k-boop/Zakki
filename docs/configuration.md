# 偏好与设置（preferences.json 与数据快照）

Zakki 的偏好分两层，都由应用内原生设置窗口管理，正常使用不需要编辑任何配置文件：

- **界面语言**：`appearance.language`（空 = 跟随系统，`en` / `zh-Hans`）；首启向导第一步选择，
  设置「常规」页与应用菜单可随时切换，变更经 MyGo `App.SetLocale` 即时生效并持久化。

- **preferences.json**（数据目录）：明暗模式、颜色/排版主题、字体、备份策略、
  快捷键、窗口参数。
- **笔记数据快照（zakki.json）里的标签与外观设置**：标签内容/名称/颜色、
  标签标题最大宽度、切换动画速度、顶栏动效开关、标签形状、彩色圆点、毛玻璃回退强度——这些跟随笔记
  自动保存落盘，在「标签与外观」页即时生效，无需重启。

macOS 路径：

```text
~/Library/Application Support/Zakki/preferences.json
~/Library/Application Support/Zakki/zakki.json
```

Windows 的对应目录为 `%APPDATA%\Zakki\`，与默认程序安装目录 `%LOCALAPPDATA%\Programs\Zakki` 分离。
更名前安装的旧数据目录会在升级后首次启动时自动迁移到新目录（整体搬入并按新命名改名文件，
新目录已有数据时不动旧目录仅告警）；其他平台两个文件位于同一数据目录（os.UserConfigDir）。
MyGo 的 `PathUserData` 同样指向此目录，窗口状态与更新器辅助状态不会另建目录。
开发运行（`go tool mygo dev` / `go run`，即 `mygo.IsDev()`）使用独立的
`~/Library/Application Support/Zakki Dev/`，不做旧目录迁移；正式目录留给安装版
（本地 `make build` 产物也算正式），两边数据互不污染。
`updater.json` 由 MyGo 原生更新器管理检查时间、跳过版本和自动下载选择，不改动 `preferences.json` 的结构。
默认只手动检查；更新入口及发布要求见 [发布与更新](release.md)。

## 设置窗口

单实例、非模态窗口，独立记忆位置和尺寸（初始 760×600，最小 640×480）；
重复打开只聚焦已有窗口，应用菜单只保留「设置… ⌘,」一个入口，标签与外观、快捷键等页面从设置窗口左侧导航进入。
所有字段**即时生效并自动保存**；非法数字不提交，保留正在编辑的输入并显示行内错误；
每页提供「恢复本页默认值」（需确认，不清除笔记或备份；标签页除外——
标签内容属于笔记数据，用删除/清空入口并走安全备份）。

### 标签与外观

标签是动态的：默认 7 个，最多 12 个，至少保留 1 个。标签内容、名称与颜色
属于**笔记数据**（存在 zakki.json 的 `tabs` 里，随自动保存与退出最终保存落盘）。

| 设置/操作 | 行为 |
|---|---|
| 标签列表 | 颜色点（点它切换到该标签；行内展开 12 色调色板改色）、名称即时保存（未命名只显示圆点）、⌃1–9 提示、上移/下移、删除 |
| 删除 | 至少保留 1 个；有内容的标签先弹确认，确认后先做安全备份，备份失败自动取消 |
| 新建标签 | 新增空标签并切换过去、聚焦内容编辑；自动分配未使用的调色板颜色；达到 12 个显示原因 |
| 标签标题最大宽度 | 80–220 DIP（默认 120）；超出用 … 省略 |
| 切换动画速度 | 慢 / 正常 / 快 / 更快（液态融合动画节奏） |
| 顶栏动效 | 关闭后切换标签瞬间完成，不播放液态融合动画；与系统「减少动态效果」同路径 |
| 标签形状 | 非当前标签的示意形状：圆点（默认）/ 圆环 / 方点 / 圆角方 / 胶囊 / 菱形 / 六边形 / 三角 / 星形 / 水滴 / 叶片；当前标签始终是标题胶囊 |
| 彩色圆点 | 关闭后圆点与胶囊用中性色，不区分标签颜色 |
| 毛玻璃回退强度 | 无系统材质平台上的半透明层浓度（20–90%） |


### 常规

| 设置 | 行为 |
|---|---|
| 窗口置顶 | 即时生效（与 ⌥⌘T、工具栏置顶按钮同源） |
| 按 Esc 隐藏窗口 | 即时生效 |
| 记忆主窗口位置与尺寸 | 从**下次创建主窗口**起生效（关闭窗口后重新打开即应用），无需重启应用 |

页内同时显示一次性迁移结果，以及偏好文件/旧配置异常时的恢复入口。

### 外观

- **明暗模式**：跟随系统 / 浅色 / 深色，即时应用到已打开窗口
  （「标签与外观」页也可调，同一来源）。
- **整套主题**：「手绘手账」一键同时套用手绘颜色主题、手账排版主题与手写正文字体（之后仍可分别调整）。
- **颜色主题**（与排版相互独立；点「手绘」卡片会同时切到手账排版与手写字体）：经典（随标签七色配色）、纸白、暖砂、雾青、石墨、手绘（米黄纸张 + 朱红批注 + 荧光笔选区）；
  每套均有浅/深两组底色，正文/次级文字对实际背景 ≥ 4.5:1（有自动化对比度测试）。
  主窗口自液态标签版起使用**窗口级毛玻璃（Vibrancy）+ 中性背景**，不再随标签
  切换整片内容背景色；标签颜色只出现在圆点/胶囊、焦点 accent 与状态栏小标识上。
  macOS 提供系统材质；不支持材质的平台自动回退为主题半透明色，强度可在
  「标签与外观」页调整，功能不受影响。
- **Markdown 排版主题**：Sonnet（Typora）、便签、清晰（16px/1.65）、
  书页（宋体 17px/1.8）、紧凑（15px/1.5）、手账（16px/1.75；点阵纸与页边红线、铅笔线框代码块与表格、马克笔引用条、荧光笔标题与粗体、波浪下划线链接、手绘勾选框与列表符号、铅笔波浪分隔线）；标题字号 = 正文基准 × 主题比例。
- **排版微调**：中文字体（霞鹜文楷（默认，内置单份资源） / 系统苹方 / 宋体 / 手写 / 手札体：
  两者同用内置手写字体，标题靠字号与装饰区分）、
  西文字体（跟随中文字体 / JetBrains Mono / 系统西文 / Noteworthy / Bradley Hand）、代码字体
  （JetBrains Mono / SF Mono / Menlo）、字号（10–40）、行高（1–3）；
  清空表示「跟随 Markdown 排版主题」。主题切换不重置显式覆盖。
- **代码配色**：代码块语法着色方案（柔和 / 明快 / 跟随文本），实时预览代码卡与源码模式共用；
  默认「柔和」，「跟随文本」保持单色文字（可显式选择并始终落盘）。逐行浅层词法着色，不保证跨行结构（块注释、多行字符串只有首行着色）。
- **预览**：只读示例（中英文、标题、链接、代码、引用、任务、表格），
  用所选排版主题 + 当前颜色主题渲染，不套用户覆盖。

### 备份与数据

| 设置/操作 | 说明 |
|---|---|
| 外部备份·选择文件夹 | 每次本地备份成功后把同一份备份镜像到该文件夹：云盘同步文件夹（iCloud、坚果云等）即云备份，Git 仓库的本地 clone 可版本化；可跳过（仅本地备份）。拒绝选应用数据目录与本地备份目录（含子目录；路径解析跟随符号链接），选定后试写验证可写；原生目录选择器可选新建文件夹 |
| 外部备份·打开文件夹 / 更换 / 断开 | 打开所选文件夹（访达）；未配置时只显示「选择文件夹…」入口 |
| Git 自动化 | 关闭 / 自动提交 / 提交并推送；仅当所选文件夹是 Git 仓库（含 .git）时可选。备份写入后后台对备份文件执行 `git add` + 提交（提交信息 `backup: zakki-<时间戳>`，无变更跳过），可选推送；使用本机 git 与已有凭证，失败只提示（状态栏「镜像失败」加粗 + 设置页详情），不影响备份本身；忙碌期间自动合并为一次补跑 |
| 编辑后自动备份最小间隔 | 1–1440 分钟；是**节流间隔**，不是独立定时备份 |
| 备份保留数量 | 1–1000 份；本地与外部镜像共用；减小后在下一次成功备份时才裁剪，不立即删除 |
| 启动时备份 | 应用启动且已有数据文件时先做一份备份 |
| 立即备份 | 与 ⌘S 相同：保存并无条件写一份备份（含外部镜像） |
| 打开备份目录 | 在访达中打开真正的 `backups/` 目录 |
| 显示数据位置 | 在访达中定位 `zakki.json` |
| 写回数据文件 | 仅当数据文件处于写保护（损坏且无可用备份）时出现；确认后解除保护并写回 |

### 首启初始化向导

仅在**全新安装**（数据文件不存在）时出现，独立窗口（`StateKey: "onboarding"`），主窗口
等向导结束（或跳过/关窗）再创建。三步均可返回：

1. **语言**：English / 简体中文（跟随系统初始，选择即时生效并被记住）。
2. **备份文件夹**：预填默认路径 `~/Documents/Zakki 备份`（目录在首次备份时自动创建），
   可点「更换…」改选任意本地文件夹；Git 自动化不在向导出现（默认关闭，设置页可开）。
3. **初始标签数量**：1–12（默认 7），决定首次生成的 `zakki.json` 标签数；
   之后在设置里增删不受限。最后一步的主按钮即「完成，进入 Zakki」。

确认/跳过/关闭窗口都会立刻写入：`backup.mirrorDir`（所选或默认路径）与默认的
`zakki.json`（7 个标签与欢迎文本），以免下次启动再次弹出向导。数据落盘失败会留在
向导并提示重试；配置了外部备份时会在数据保存成功后立即做一次备份，备份失败
不阻止进入应用，状态栏/通知会提示详情。

老用户升级（已有数据文件）不出向导，`mirrorDir` 保持原值不回填；从设置页补配或修改外部备份。

### 快捷键

- 可改键命令：加粗、斜体、行内代码、插入或编辑链接、标题 1–6、正文、引用、
  无序/有序/任务列表、代码块、分隔线、插入表格，以及全局显示/隐藏主窗口。
- macOS 默认：⌘B / ⌘I / ⌘⇧E / ⌘K、⌘1–6 / ⌘0、⌘⇧Q、⌘⇧8 / ⌘⇧7 / ⌘⇧9、
  ⌘⌥C、分隔线与表格默认未绑定、全局 ⌘⇧空格。其他平台以 Ctrl 替代 Cmd。
- 按键录制：点击「更改」后按下组合键，Esc 取消；仅支持单组组合键（不支持 chord）。
- 拒绝：与已有命令或固定快捷键冲突（显示冲突名称）、仅修饰键、裸字母/数字、
  Tab/Enter/Esc 等导航输入键；全局键不能与文档键相同（避免全局键吞掉文档快捷键）。
- 固定快捷键（不开放改键）：⌘F 搜索、⌘⇧P 源码模式、⌥⌘T 置顶、
  ⌃1–9 切换标签（10–12 用顶栏或设置页访问）、⌘T 新建标签、⌘R 重命名当前标签、
  ⌘⌥←/→ 上/下一个标签（循环）、⌘S 立即备份、⌘⇧C 复制整个标签、
  系统编辑操作（剪切/复制/粘贴/撤销/全选）。删除标签只经设置页（避免与 ⌘W 冲突），
  且先做安全备份；双击顶栏胶囊也可重命名。
- 全局热键变更先注册新键，成功后再注销旧键；失败保留旧绑定并提示；
  解除绑定后托盘仍可唤起窗口。

## 标签数据与数据文件版本

笔记数据文件 `zakki.json` 当前版本为 **3**：

```json
{
  "version": 3,
  "active": 0,
  "tabs": [
    { "id": 1, "name": "工作", "text": "# 待办", "color": "#d4253a" },
    { "id": 2, "text": "" }
  ],
  "settings": {
    "themeSource": "system",
    "tabTitleWidth": 120,
    "tabAnimSpeed": 1,
    "monoDots": false,
    "glassStrength": 0.5,
    "tabMotionOff": false,
    "tabDotShape": "dot"
  }
}
```

- `tabs` 是动态标签列表；`name` 空 = 未命名（顶栏只显示圆点）；
  `color` 空/非法时按槽位回退内置 12 色调色板。
- `settings` 里的标签栏外观项（0/缺键 = 跟随默认）：`tabTitleWidth` 80–220、
  `tabAnimSpeed` 0.5–2、`monoDots` 关闭彩色圆点、`glassStrength` 0.2–0.9、
  `tabMotionOff` 关闭顶栏动效（缺键 false = 开启）、`tabDotShape` 标签形状 ID
  （缺键/未知值 = 圆点；合法值见 `tab_strip.go` 常量）。
- 版本 0/1（固定 7 点 `dots` 格式）在读取时按原顺序迁移为 7 个标签：正文原样、
  名称空、颜色用原 7 色；迁移后保存只写 `tabs`，不再写 `dots`。
- 版本 3 起排版主题 ID 更名：旧 ID 字面量（见 `notes` 包常量）载入时映射为 `note`；
  文件结构与字段不变。
  版本高于当前支持时绝不覆盖原文件（隔离原件并尝试从备份恢复）。

## preferences.json 结构

应用自动读写，通常无需关心。手工编辑时注意：未知字段、null 与非法取值会被拒绝，
文件损坏或版本超前时应用不会覆盖原文件，会在设置页提示恢复。

```json
{
  "version": 5,
  "appearance": {
    "appearanceMode": "system",
    "language": "",
    "colorTheme": "classic",
    "markdownTheme": "sonnet",
    "codeTheme": "soft",
    "bodyFont": "",
    "latinFont": "",
    "monoFont": "",
    "bodySize": 0,
    "lineHeight": 0
  },
  "window": { "alwaysOnTop": false, "hideOnEscape": true, "rememberBounds": true },
  "backup": { "intervalMinutes": 5, "keep": 20, "onLaunch": true, "mirrorDir": "", "gitMode": "off" },
  "keymap": { "overrides": { "format.bold": "CmdOrCtrl+Alt+U" } },
  "advanced": { "autosaveDelayMs": 800, "windowWidth": 400, "windowHeight": 540 }
}
```

- `appearance.bodyFont` 是中文字体，`appearance.latinFont` 是西文字体：
  两者组合成字体栈（西文在前、中文在后），英文字母与数字取西文，中文字形取中文。
  `latinFont` 空串 = 跟随中文字体，此时整篇用中文字体栈自带的西文字形。
- `appearance.monoFont` 空串 = 跟随排版主题；`bodySize` / `lineHeight` 0 = 跟随。
- `appearance.codeTheme` 空串 = 跟随文本（单色代码），其余取值 `soft`（柔和，默认）/ `vivid`（明快）；
  该键始终落盘（无 omitempty），空串是显式选择而非未设置。
- 版本 2 起分成中西文两个键。旧文件（版本 1 或无 version）读取时把 `latinFont` 留空，
  与升级前的渲染结果一致；升级后写回的文件为当前版本，旧版本程序会因版本超前而拒绝读取，
  并保留原文件不走覆盖。
- 版本 3 起 `backup` 增加外部备份两个字段：`mirrorDir` 为外部备份目的地绝对路径
  （空串 = 未配置，仅本地备份）；`gitMode` 为 Git 自动化档位（`off` / `commit` /
  `commitPush`，缺键按 `off`，仅对 Git 仓库目录有意义）。缺键的版本 2 文件升级后
  行为与升级前一致。
- 版本 4 起主题 ID 更名：`colorTheme` 旧字面量映射为 `classic`，`markdownTheme`
  旧字面量映射为 `note`（旧字面量见 `prefs` 包常量）；新增 `appearance.language`
  （空串 = 跟随系统，`en` / `zh-Hans`）。缺键行为与升级前一致。
- 版本 5 起代码配色默认「柔和」：版本 4 及更早文件从未写过 `codeTheme` 键，
  升级时统一补为 `soft`；带值文件原样保留。版本 5 文件该键始终写出，
  缺键或空串都按显式「跟随文本」处理，不再补默认。
- `keymap.overrides` 缺项用默认绑定；显式空串表示解除绑定；值为规范化 accelerator。
- `advanced` 是兼容参数（自动保存防抖毫秒、主窗口初始宽高），不在设置页展示，
  仅在旧配置携带有效值时迁移保留。

## 旧配置文件（仅供迁移）

`config.toml`（及更早的 `config.json`）**只在新版首次启动、且不存在
`preferences.json` 时被读取一次**，优先级：默认值 → 笔记内旧设置 → 旧配置显式值
（TOML 优先于 JSON）。迁移成功以 `preferences.json` 原子写入为完成标志；
两个旧文件此后原样保留、不再读取，应用也不再生成或改写它们。
旧排版值映射到当前排版主题，颜色主题映射为经典主题（保留七点底色体验），
字体覆盖、窗口参数、备份策略与全局热键一并迁移。
